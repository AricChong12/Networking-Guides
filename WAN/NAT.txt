NAT

Static NAT

1. Configure Interface IP Address

R1(config)# interface g0/0
R1(config-if)# ip address 200.200.200.1 255.255.255.224
R1(config-if)# ip nat outside
R1(config-if)# no shutdown

R1(config)# interface g0/1
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# ip nat inside
R1(config-if)# no shutdown

Format: ip nat [inside/outside]

2. Configure static NAT mapping

R1(config)# ip nat inside source static 192.168.1.142 200.200.200.10

Format: ip nat inside source static [host address] [NAT translated address]

3. Configure Default Route (if needed)

R1(config)# ip route 0.0.0.0 0.0.0.0 200.200.200.2

4. Static NAT Verification

show ip nat translations
show ip nat statistics
show running-config | include nat


Dynamic NAT

1. Configure Traffic

R1(config)#access-list 1 permit 192.168.1.0 0.0.0.127 

Format: access-list [1-99] permit [NA] [Wildcard Mask]

2. Configure pool of address of NAT

R1(config)#ip nat pool NAT-POOL-R1 200.200.200.5 200.200.200.8 netmask 255.255.255.240 

Format: ip nat pool [Pool Name] [translated address range 1] [translated address range 2] netmask [SM]

3. Associate ACL with NAT pool

R1(config)#ip nat inside source list 1 pool NAT-POOL-R1 

Format: ip nat inside source list [ACL Created] pool [Pool Name]

4. Configure NAT interface

R1(config)#int g0/0.10 
R1(config-subif)#ip nat inside 
R1(config)#int g0/0.20 
R1(config-subif)#ip nat inside 
R1(config-subif)#int s0/0/0 
R1(config-if)#ip nat outside 


PAT

1. Configure Traffic that will be permitted

R3(config)# access-list 1 permit 172.16.1.0 0.0.0.127 

Format: access-list [1-99] permit [NA] [Wildcard Mask]

2. Associate ACL with PAT enabled

R3(config)#ip nat inside source list 1 int s0/0/1 overload

Format: ip nat inside source list [ACL Created] int [interface name] overload

3. Configure NAT interface

R3(config)#int g0/0.10 
R3(config-subif)#ip nat inside 
R3(config)#int g0/0.20 
R3(config-subif)#ip nat inside 
R3(config-subif)#int s0/0/1 
R3(config-if)#ip nat outside 


NAT Implementation Verification

show ip nat trans


Extra Examples

R1(config)#ip access-list extended EXTERNAL_TRAFFIC_NAT 
R1(config-ext-nacl)# permit tcp any host 200.200.200.3 eq 443 
R1(config-ext-nacl)# permit tcp any host 200.200.200.3 eq 21 
R1(config-ext-nacl)# deny ip any any 
R1(config)#int s0/0/0
