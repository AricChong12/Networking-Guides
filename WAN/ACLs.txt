Standard ACL

1. Create a standard ACL

Router(config)# access-list 10 deny 192.168.10.0 0.0.0.255
Router(config)# access-list 10 permit any

Format: 
access-list [1-99] deny [NA] [SM]
access-list [1-99] permit any


2. Apply Standard ACL to Interface

Router(config)# interface GigabitEthernet0/1


3. Outbound or Inbound


Router(config-if)# ip access-group 10 out
Router(config-if)# ip access-group 10 in

Format: ip access-group [1-99] [in/out]


Standard ACLs Verification

show access-lists
show running-config



Extended ACLs

Extended Numbered ACL

1. Configure ACL to permit FTP and ICMP

R1(config)# access-list 100 permit tcp host 192.168.1.126 host 192.168.1.142 eq ftp

Format:
access-list [100-199/2000-2699] permit [protocol] host [source address] host [destination address] eq [service port]

R1(config)# access-list 100 permit icmp host 192.168.1.126 host 192.168.1.142  
R1(config)# access-list 100 deny ip any any


2. Apply ACL on interface

R1(config)# interface g0/1.10 
R1(config-if)# ip access-group 100 in


Extended Named ACL

1. Configure Named Extended ACL

R1(config)# ip access-list extended EXTERNAL_TRAFFIC 

Format: ip access-list extended [ACL Name]

R1(config-ext-nacl)# permit tcp host 172.16.1.126 host 192.168.1.142 eq https 

Format: permit [protocol] host [source address] host [destination address] eq [port]

R1(config-ext-nacl)# permit tcp host 172.16.1.126 host 192.168.1.142 eq ftp 

Format: permit [protocol] host [source address] host [destination address] eq [port]

R1(config-ext-nacl)# deny ip any any


2. Apply ACL to interface

R1(config)# interface s0/0/0 
R1(config-if)# ip access-group EXTERNAL_TRAFFIC in
