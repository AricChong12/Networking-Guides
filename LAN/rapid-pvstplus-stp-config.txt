Examples
1. Configures VLANs


2. Configure STP mode

S1(config)# spanning-tree mode rapid-pvst
S2(config)# spanning-tree mode rapid-pvst
S3(config)# spanning-tree mode rapid-pvst


3. Configure Rapid Spanning Tree PVST+ Load Balancing

S1(config)# spanning-tree vlan 1,10,30,50,70 root primary
S2(config)# spanning-tree vlan 1,10,20,30,40,50,60,70,80,99 root secondary
S3(config)# spanning-tree vlan 20,40,60,80,99 root primary

Tips: 
root primary is root bridge, root secondary is backup bridge


Verification

sh spanning-tree



At Host Port
1. Configure PortFast 

int range f0/6, f0/11, f0/18
spanning-tree portfast


2. Configure BPDU Guard

int range f0/6, f0/11, f0/18
spanning-tree bpduguard enable



Verification

sh run
