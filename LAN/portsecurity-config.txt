Examples
1. Configure basic security on all ports connected to host devices

S1(config)# interface range fa0/1-3 
S1(config-if-range)# switchport mode access
S1(config-if-range)# switchport port-security
S1(config-if-range)# switchport port-security maximum 1
S1(config)# interface range fa0/1-2
S1(config-if-range)# switchport port-security mac-address sticky
S1(config)# interface fa0/3
S1(config-if)# switchport port-security mac-address 0010.1197.14c4

Tips: 0010.1197.14c4 is server mac address


2. Sets violation mode

S1(config)# int fa0/1
S1(config-if)# switchport port-security violation shutdown

OR

S1(config)# int fa0/2
S1(config-if)# switchport port-security violation restrict


Verification of port security

sh port-security address
sh port-security int f0/1
